# claude-status

claude-status is a personal utility, used by one person on that person's own computer. It copies a short project status file from a local machine to the author's own Google Drive, using [rclone](https://rclone.org/), so that the author can read it from other tools. It is not a product or a service, and it is not available to anyone else. It is not affiliated with Google or Anthropic.
